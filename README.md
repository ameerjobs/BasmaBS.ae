# BasmaBS.ae
# Bassmah Bookstore (v2)

## Run the project
Option 1: double-click `index.html`.
Option 2 (local server, needs Python):
    python3 -m http.server 8000
then open http://localhost:8000

## Changes in v2
- Rebranded from Mono Store to Bassmah Bookstore, with the logo in the header (images/logo.jpg)
- Three books added with covers: How to Own Your Own Mind, The Big Sleep, Animal Farm
- Contact page and footer include Instagram and phone +971 56 309 7595
- Currency changed to AED. Book prices are placeholders: edit `data-price` on each `.product` in index.html and shop.html
